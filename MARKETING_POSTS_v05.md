## 💼 LinkedIn Post (Professional / Enterprise focus)

**Headline:** AI Agents just got a memory upgrade. Announcing Axon v0.5. 🧠

**Body:**
I'm excited to announce the release of **Axon Framework v0.5.1** — now stable and available on PyPI.

When we started Axon, the goal was simple: bring the developer experience of FastAPI to the world of AI Agents. No complex abstractions, just clean, typed Python.

With v0.5, we're tackling the two biggest hurdles in production AI: **State** and **Reliability**.

🚀 **What's New?**

1.  **Persistent Memory:** Agents now possess long-term memory across sessions using a local SQLite backend. This allows for personalized, context-aware interactions that improve over time.

2.  **Production Reliability:** We've baked in robust Error Retry logic with exponential backoff into every core tool. Network blips or API rate limits won't crash your agents anymore.

3.  **Plugin Ecosystem:** A standardized way to extend Axon's capabilities. We're launching with tools for Web Search, File Management, and Email.

**Why Axon?**
While other frameworks prioritize complexity, Axon prioritizes **Developer Experience** and **Production Readiness**.
- Type-safe (Pydantic)
- Real-time streaming
- Zero-boilerplate setup

The framework is open-source and ready for your next project.

📦 **Install:** `pip install axon-framework`
